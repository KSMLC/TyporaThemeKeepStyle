A compact variant of the [Clean](/theme/Clean/) theme with tighter spacing for focused writing.

Designed and tested on MacOS. Not fully tested, but should work for Windows/Linux.

## Installation

1. **Download the theme files**

- https://github.com/channingwalton/typora-themes/tree/main/clean-compact/clean-compact.css

2. **Locate Typora's theme folder**

   - Open Typora → Preferences → Appearance → Open Theme Folder.

3. **Copy theme files**

   - Place the css file into the theme folder.

4. **Apply the theme**

   - Restart Typora, then select **Clean Compact** from the Themes menu.
