# LaTeX Typora

LaTeX Typora is a family of Typora themes inspired by classic LaTeX documents, including a more code-forward dark variant for developer-heavy Markdown.

<p align="center">Dark mode</p>

## Features

- Includes `latex.css`, `latex-dark.css`, and `latex-dev-dark.css` for reading-focused and code-heavy workflows.
- Bundles Latin Modern, JuliaMono, iA Writer Mono, and Noto Nastaliq Urdu font assets for offline use.
- Uses LaTeX-style spacing and justified prose in `latex` / `latex-dark`, plus a scan-friendly left-aligned layout in `latex-dev-dark`.
- Supports Urdu and Persian Nastaliq in `latex` / `latex-dark` via `lang="ur"` and `lang="fa"` on block or inline content.
- Refines tables, blockquotes, links, footnotes, math, diagrams, code fences, and Typora UI surfaces in a consistent monochrome look.

## Installation

1. Download the latest release and extract it.
2. In Typora, open `Preferences` -> `Appearance` and click `Open Theme Folder`.
3. Copy `latex.css`, `latex-dark.css`, `latex-dev-dark.css`, and the `latex_fonts` folder into Typora's theme folder.
4. Restart Typora and select `latex`, `latex-dark`, or `latex-dev-dark` from the Themes menu.

> Designed and tested on macOS. Not fully tested, but should work for Windows/Linux.

For source, updates, and installation notes, visit [shamsghi/LatexTypora](https://github.com/shamsghi/LatexTypora).
