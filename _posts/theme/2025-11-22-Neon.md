A Neon theme.

Designed and tested on MacOS. Not fully tested, but should work for Windows/Linux.

Some screenshots: 

![Neon-1](/media/theme/lcars/neon-1.png)

## Installation

1. **Download the theme files**

- https://github.com/channingwalton/typora-themes/blob/main/neon/neon.css

2. **Locate Typora’s theme folder**

   - Open Typora → Preferences → Appearance → Open Theme Folder.

3. **Copy theme files**

   - Place the css file into the theme folder.

4. **Apply the theme**

   - Restart Typora, then select **Neon** from the Themes menu.
