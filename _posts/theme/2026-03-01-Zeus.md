# Zeus

A dark Typora theme with warm orange accents, clean typography, and VS Code-inspired syntax highlighting.

## Features

- Dark background (`#1e1e1e`) with warm orange heading accents
- Blue links and blockquotes for visual contrast
- VS Code Dark+ code syntax highlighting
- Open Sans body font with Cascadia Code for code
- Responsive content width
- Styled admonitions/callouts
- Custom orange checkbox styling
- Full Typora UI coverage (sidebar, settings, context menus, scrollbars)

## Platform

Designed and tested on Windows. Not fully tested, but should work for macOS/Linux. This theme does not include styles for macOS "unibody" style.
