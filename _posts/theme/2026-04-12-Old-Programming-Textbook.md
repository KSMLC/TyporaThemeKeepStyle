A collection of single-toned, brutalist, eye-friendly light themes for Typora, inspired by the timeless aesthetic of classic computer science and programming textbooks.


# Look and feel

![Old Programming Textbook](/media/theme/Old-Programming-Textbook/old-programming-textbook.png)

# 🎨 Built for Eye Care

This theme completely strips out pure white (#FFFFFF) and harsh blue light. It uses warm, paper-like backgrounds and deep, earthy text tones to drastically reduce eye strain during long writing and coding sessions.

It comes in 5 distinct, zero-blue-light flavors:

🍵 Matcha Terminal: Warm sage off-white with deep forest charcoal and vibrant green accents.

☕ Mocha: A warm sepia and cream palette mimicking aged textbook paper.

🍠 Taro: Dusty, muted lavender that feels playful but stays highly legible.

🫖 Earl Grey: A warm, neutral slate-grey for a pure monochrome experience.

🍑 Peach: Soft coral and terracotta tones inspired by faded textbook covers.

# ✨ Features

Playful Brutalism: Sharp geometric edges, solid offset shadows, and a "neo-brutalist" UI.

Beautiful Free Typography: Uses Google's IBM Plex Sans (body), IBM Plex Mono (code), and Space Grotesk (headings) dynamically. No local font installation is required!

Custom UI Elements: * <kbd> tags are styled to look like physical mechanical keyboard keys.

<mark> tags are redesigned as sharp, muted highlighter strips (no default yellow!).

Custom, single-toned syntax highlighting for code blocks.

Interactive images that "lift" when hovered.

# Note

This theme has been designed and tested on macOS. Not fully tested, but should work for Windows/Linux. But this theme does not include styles for Windows "unibody" style.
