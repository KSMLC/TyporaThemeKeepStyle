A **print-optimized** theme designed for minimal paper usage and professional output.

## Features

- **Compact 9pt typography** — fits more content per page, saves paper
- **Smart page breaks** — headings stay with following content, no orphan lines
- **Tiny 6pt code blocks** — perfect for wide ASCII diagrams and technical docs
- **Clean output** — no background or borders on code blocks
- **Cross-platform** — tested on macOS, with styles for Windows and Linux

## Variants

| Theme | Paper Format |
|-------|--------------|
| Print | DIN A4 (210 × 297 mm) |
| Print Letter | US Letter (8.5" × 11") |
