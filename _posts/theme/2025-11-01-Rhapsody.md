# 🍎 Rhapsody · Typora 专属皮肤主题
> 🌐 English version: [Rhapsody-introduciton](/media/theme/Rhapsody/Rhapsody-introduction-EN.md)

> “色彩，是思想的延伸；写作，是秩序与灵感的交响。”

**Rhapsody** 是一款以「多彩、梦幻、灵动」为核心设计理念的 Typora 主题。它不是简单换个配色，而是用 **高饱和撞色 + 光影能量层 + 分层标题体系**，给 Markdown 写作做了一次“视觉级重构”，同时又遵守 Typora 的编辑器结构，不去乱动 HTML。

## 🌈 设计理念

Rhapsody 的灵感来自 **《镜之边缘》式高饱和撞色** + **哲学符号美学**。  
它想表达的不是“好看”本身，而是：

- 色彩可以作为思想的外延；
- 写作场景也可以是有节奏、有呼吸、有能量层的；
- 所有效果都在 **不改 Typora HTML 结构** 的前提下完成，方便导出和升级。

---

## ✨ 主题特色

- 🎨 **六级标题独立风格**：h1 是 Appleron 光带，h2–h6 各有字体与图标，不是一把梭的粗体放大。
- 💡 **光影与能量流动**：写作区有柔光、渐变、泡泡/粒子运动，营造“活的版心”。
- 📦 **模块化 CSS 架构**：`layout.css / typography.css / math.css / table.css / export_patch.css` 分层管理，方便你以后拆/关/替换。
- 🧮 **导出友好**：自带 HTML/PDF 导出补丁，解决你之前说的“导出 HTML 背景丢失 / 对齐跑偏”那类问题。
- 🧠 **彩蛋体系**：标题图标、角标、能量条都可以做成小机关，但都只是 CSS，不动 DOM。

## ⚙️ 安装与启用

1. 打开 Typora → 偏好设置 → 外观 → **打开主题文件夹**  
2. 把仓库里的 **`rhapsody.css`** 和同级的 **`Rhapsody/` 资源目录** 一起放进去  
   （注意：入口文件在外面，资源目录在里面，保持相对路径）
3. 重启 Typora，在主题列表中选择 **Rhapsody**

> ⚠️ 不要把 `rhapsody.css` 塞进 `Rhapsody/` 里，不然相对路径会找不到图片和子样式。
