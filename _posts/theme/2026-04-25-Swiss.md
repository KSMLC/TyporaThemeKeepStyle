# Swiss

Swiss is a Typora theme inspired by Swiss / International Typographic Style. It focuses on clear hierarchy, restrained color, deliberate spacing, and a steady grid-like reading rhythm for structured Markdown writing.

![Swiss preview](/media/theme/swiss/intro.png)

## Features

- Uses a warm paper-like background with crisp white content surfaces.
- Builds document hierarchy through strong typographic scale, alignment, and ruled headings.
- Applies a restrained deep red accent for headings, lists, borders, and emphasis.
- Keeps code blocks, tables, blockquotes, and regular prose visually consistent.
- Works well for technical documents, course assignments, research notes, resumes, project pages, and portfolio-style Markdown.

## Installation

1. Download the latest release and extract it.
2. In Typora, open `Preferences` -> `Appearance` and click `Open Theme Folder`.
3. Copy `swiss.css` into Typora's theme folder.
4. Restart Typora and select `Swiss` from the Themes menu.

> Designed with a Swiss / International Typographic Style approach. Please report platform-specific display issues in the project repository.

For source, updates, and installation notes, visit [ChivaLryCieux/swiss-theme](https://github.com/ChivaLryCieux/swiss-theme).
