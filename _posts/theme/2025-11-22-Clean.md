## Installation

1. **Download the theme files**

- https://github.com/channingwalton/typora-themes/tree/main/clean/clean-light.css

2. **Locate Typora’s theme folder**

   - Open Typora → Preferences → Appearance → Open Theme Folder.

3. **Copy theme files**

   - Place the css file into the theme folder.

4. **Apply the theme**

   - Restart Typora, then select **Clean Light** from the Themes menu.
