A dark theme for Typora based on [Nord](/theme/Nord/) color palette, migrated and extended from the [Blue-Topaz Obsidian theme](https://github.com/PKM-er/Blue-Topaz_Obsidian-css).

Designed and tested on macOS. Not fully tested, but should work for Windows/Linux.

## Features

- Nord-based dark color palette with Aurora accent colors
- Colored headings (H1–H5 with distinct colors: red → orange → yellow → green → purple)
- Material Palenight code syntax highlighting
- SVG custom checkboxes (Obsidian-style)
- Zebra-striped tables with blue hover overlay
- Fluorescent yellow highlighter for `<mark>`
- Keyboard shortcut `<kbd>` styling
- CJK optimized with LXGW WenKai font support
- Font ligatures enabled

## Installation

1. Download the theme files.
2. Open Typora → Preferences → Appearance → Open Theme Folder.
3. Copy `blue-topaz.css` into the theme folder.
4. Restart Typora, then select **Blue Topaz** from the Themes menu.
