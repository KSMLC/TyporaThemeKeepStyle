# Bloom theme for Typora

> 写作值得被温柔对待。

Bloom（绽放 / 成长）是一套为**长期写作**而设计的 Typora 主题。  
它追求安静、克制与温柔的表达，不过度装饰，不喧宾夺主，让文字始终成为视线的中心。  
配色基于 **OKLCH** 色彩空间调校，低饱和、亮度均衡，确保不同色相之间的视觉统一。  
这个主题诞生于创作者成为父亲之后，更在意时间、陪伴，以及那些会被反复翻阅的文字。  

## 设计语言

- **文字优先**：所有设计都为内容让路  
- **长期可用**：不追求第一眼惊艳，而追求长期耐看  
- **感知均匀**：使用 OKLCH 调色，亮度与对比更平衡  
- **克制而非贫乏**：颜色与装饰谨慎使用  
- **情绪稳定**：白天与夜晚都保持平和  

## 主题特点

1. **长文友好**：行距偏松、段落呼吸感强，阅读负担更轻 ✍️  
2. **昼夜一致**：16 套主题统一排版系统，切换不破坏习惯 🌗  
3. **界面减噪**：边框与阴影轻量化，让内容比 UI 更突出 🌿  
4. **细节克制**：标题不过度放大，列表、引用、代码块连续顺滑 🧩  
5. **OKLCH 调色**：低饱和、亮度均衡，跨色相依然稳定 🧪  

## 主题系列

包含十六套主题（8 套浅色 + 8 套深色）：

### 🌤 浅色系列 (Light)

- **Bloom Petal** (花瓣)：暖粉白 + 玫瑰粉，柔和温润  
- **Bloom Mist** (雾蓝)：冷浅灰 + 深雾蓝，深邃克制  
- **Bloom Verdant** (草木)：极浅淡绿 + 豆沙绿，治愈自然  
- **Bloom Stone** (暖石)：暖米白 + 红棕土，温润如陶瓷  
- **Bloom Amber Orange** (琥珀)：现代琥珀橙，清爽活力  
- **Bloom Spring** (薰衣草)：淡雅紫白 + 薰衣草紫，浪漫花海  
- **Bloom Ripple** (涟漪)：清冷高级的青碧色  
- **Bloom Ink** (水墨)：宣纸白 + 朱砂红，东方极简  

### 🌙 深色系列 (Dark)

- **Bloom Petal Dark** (花瓣暗夜)：深玫瑰黑 + 玫瑰粉  
- **Bloom Mist Dark** (雾蓝暗夜)：莫兰迪雾蓝暗色版  
- **Bloom Verdant Dark** (草木暗夜)：深墨绿 + 莫兰迪绿  
- **Bloom Stone Dark** (暖石暗夜)：深暖棕 + 红棕土  
- **Bloom Amber Orange Dark** (琥珀暗夜)：篝火般的琥珀橙  
- **Bloom Spring Dark** (薰衣草暗夜)：深紫黑 + 薰衣草紫  
- **Bloom Ripple Dark** (涟漪暗夜)：深青碧色  
- **Bloom Ink Dark** (水墨暗夜)：墨池黑 + 朱砂红

十六套主题在排版、比例、节奏上保持一致，只改变色彩氛围。

## 安装

1. 从 [Releases](https://github.com/webkubor/typora-Bloom-theme/releases/latest) 下载最新主题包  
2. 打开 Typora → 偏好设置 → 外观 → 打开主题文件夹  
3. 将 `dist/` 下的 `bloom-*.css` 与 `bloom/` 文件夹复制进去  
4. 重启 Typora，在主题菜单中选择 Bloom 系列即可
